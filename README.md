## ✨ 功能一览

| 功能 | 说明 | 需要真实模型？ |
| --- | --- | --- |
| 🎵 **音色库** | 导入 wav/mp3/m4a/flac，自动校验时长/采样率/噪声/削波，可命名、删除、复用、绑定模型 | 否（演示即可） |
| 🧬 **克隆音色** | 一段参考音频 → 音质报告 + 相似度预估 → 保存为可用音色 | GPT-SoVITS |
| 🔤 **文字转语音（TTS）** | ≤1000 字，语速/音调/音量可调，中文/英文/日文，用克隆音色朗读 | GPT-SoVITS |
| 🔄 **声音转换（VC）** | 上传或录制声音 → 转换成目标音色；转换强度、升降调、干湿比、去噪，前后对比 | RVC |
| ⚡ **实时变声** | 设备选择、原声/变声一键开关、干湿比、输入/输出音量、电平表 | RVC |
| 🕘 **历史记录** | 回听、删除、重新导出所有生成结果 | 否 |
| ⚙️ **设置** | ffmpeg、GPT-SoVITS、RVC、输出目录、语音水印、逐音色绑定模型 | 否 |

> 💡 **没有 NVIDIA 显卡 / 不想下载模型？** 内置演示引擎（SAPI 朗读 + DSP 变调）可以让你先完整体验一遍所有功能流程，只是演示引擎**不改变音色**。

## ⬇️ 下载与安装

### 方式 1：源码运行（推荐，最新版）

```powershell
# 1. 下载源码（任选其一）
git clone https://github.com/zmt123-zmt/AI-voice-changer.git
# 或：GitHub 页面 Code → Download ZIP 解压

# 2. 进入项目目录，一键安装依赖（自动创建 .venv）
cd AI-voice-changer
.\setup.ps1

# 3. 启动
.\run.ps1
```

> 如果 PowerShell 提示脚本被禁止，先执行：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
> 如果系统 Python 已装好依赖，可跳过 setup.ps1，直接 `python -m app.main` 启动。

### 方式 2：编译 exe 启动器（双击即用）

项目自带启动器编译脚本（需要 .NET Framework 4.x，Windows 自带）：

```powershell
# 双击 build_exe.cmd，或在项目目录执行：
.\build_exe.cmd
```

编译成功后在项目根目录生成 `AI-change-voice.exe`，以后**双击它即可启动**，无需再开命令行。

### 方式 3：直接使用系统 Python

```powershell
pip install -r requirements.txt
python -m app.main
```

## 📖 分页使用教程

### 1️⃣ 音色库（所有功能的基础）

- 点 **导入音频**，选择 wav/mp3/m4a/flac 文件。
- 应用自动校验：时长、采样率、噪声、削波，并给出音质报告。
- 导入时可填写**参考文字**（这段音频说了什么）——逐字准确能显著提升克隆稳定性，留空也能用。
- 卡片上可操作：命名 / 删除 / **参考文字**（随时编辑）/ **多参考**（挂多条参考音频）/ **RVC 模型**（绑定专属模型，见下）。

### 2️⃣ 克隆音色

- 在音色库选中一个音色 → 点 **克隆**。
- 查看音质报告与**相似度预估**（仅作提示）。
- 保存为"零样本参考音色"（GPT-SoVITS 直接使用）或"RVC 训练音色"入口。

### 3️⃣ 文字转语音（TTS）

- 选择音色（来自音色库）→ 输入文字（≤1000 字）→ 选语言（中文/英文/日文，或自动）→ 调整**语速/音调/音量** → **生成**。
- 生成后可直接试听、导出 wav/mp3、保存到历史记录。
- 勾选 **播放到虚拟声卡**（需安装 VB-Cable）可把声音送入微信等应用，见 [微信语音条教程](docs/教程-克隆声音发微信语音条.md)。

### 4️⃣ 声音转换（VC）

- 上传音频或现场录制 → 选择目标音色 → 调整参数：
  - **转换强度 / 像训练样本**：越高越接近目标音色
  - **音调（升降调 ±24）**：男女声转换常用（男→女一般 +12 以上）
  - **干湿比 / 去噪**：混合原声比例、降噪强度
- 点 **开始转换**，支持 **转换前后对比试听**。

### 5️⃣ 实时变声

- 选择输入设备（麦克风）与输出设备（扬声器/耳机）。
- 选择音色 → 打开 **变声开关** → 对着麦克风说话即可实时听到变声。
- 可调：干湿比、输入/输出音量，内置电平表便于调试。
- 首次启动会加载 RVC 模型（几秒~几十秒），之后实时处理。

### 6️⃣ 历史记录

- 自动保存所有 TTS / VC / 实时变声的生成结果。
- 可回听、删除、**重新导出**（格式与采样率在设置中配置）。

### 7️⃣ 设置

| 分组 | 说明 |
| --- | --- |
| 常规 | 语言、输出格式（wav/mp3）、采样率（24k/44.1k/48k，默认 48k）、输出目录 |
| ffmpeg | 自动使用内置 ffmpeg；可指定自定义 ffmpeg 路径 |
| GPT-SoVITS | API 地址（默认 `http://127.0.0.1:9880`） |
| RVC | 模型文件 `.pth`、索引 `.index`、F0 算法、默认升调、索引比率、说话人 id |
| 水印 | 可选：为生成音频附加语音水印声明文件 |
| 引擎状态 | 底部实时显示各引擎连接状态，便于排查 |

## 🤖 接入真实 AI 模型

应用内置两个演示引擎，无需模型即可跑通流程。要获得真实的"音色克隆 / 转换"效果，按下表接入：

| 功能 | 需要安装 | 用在哪 |
| --- | --- | --- |
| 克隆朗读（TTS） | **GPT-SoVITS** | "文字转语音"页，用你的音色朗读文字 |
| 音色转换（VC / 实时） | **RVC** | "声音转换"页、"实时变声"页 |

### 路线 A：GPT-SoVITS（克隆朗读）

**① 安装整合包（推荐）**

1. 打开 GPT-SoVITS 官方仓库 Release 页：`https://github.com/RVC-Boss/GPT-SoVITS/releases`
2. 下载最新 **Windows 整合包**（自带 Python 环境与模型权重，解压即用）。

**② 启动 API 服务**（在整合包根目录打开 PowerShell，保持窗口开着）

```powershell
.\runtime\python.exe api.py -a 127.0.0.1 -p 9880
```

看到 `Uvicorn running on http://127.0.0.1:9880` 即就绪。

**③ 应用设置**

1. 打开应用 → **设置 → GPT-SoVITS 卡片**。
2. 只填 **API 地址**（默认值 `http://127.0.0.1:9880` 已是正确值）。
   > ⚠️ "代码目录 / 服务脚本"**建议留空**：应用自动启动 API 用的是应用自己的 Python，与 GPT-SoVITS 环境不兼容，手动启动 API 窗口最稳。
3. 保存后，设置页底部引擎状态应显示 `TTS：GPT-SoVITS（AI 克隆）— API 已连接`。

**④ 使用**

1. **克隆音色**页：导入一段 **5~30 秒干净人声**（无音乐、无噪声），保存到音色库。
2. 在音色库中填写该音频的**参考文字**（说了什么，逐字准确）。
3. **文字转语音**页：选择该音色 → 输入文字 → 生成。声音应明显像参考音频。

### 路线 B：RVC（音色转换 / 实时变声）

**① 安装 rvc-python**（装到应用自己的 .venv）

```powershell
# 给应用环境装 CUDA 版 PyTorch（RTX 4060 用 CUDA 12.1，约 2.5GB）
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu121
.\.venv\Scripts\python.exe -m pip install rvc-python

# 验证 GPU 可用（输出 True 才正确；输出 False 说明装成了 CPU 版，实时变声会卡）
.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"
```

**② 获取模型（.pth）**，二选一：

- **下载现成模型**：找已获授权的公开 RVC 模型（`.pth`，如 HuggingFace / 模型分享站），下载到任意目录。
- **自己训练**：见 [RVC 模型自训指南](docs/RVC训练指南.md)（WebUI 训练 3~10 分钟干净人声 → 导出 `.pth` + `.index`）。

**③ 应用设置**

1. 打开应用 → **设置 → RVC 卡片**。
2. 填写：**模型文件**（`.pth` 完整路径，必填）、**索引文件**（`.index`，建议填，提升音质）、**F0 算法**（默认 `rmvpe`，唱歌用 `crepe`）。
3. 保存后底部应显示 `VC：RVC（AI 音色转换）— rvc-python 模式`。

**④ 使用**

- **声音转换**页：选择音色 → 上传/录制你的声音 → 开始转换。
- **实时变声**页：选择音色 → 选输入/输出设备 → 打开"变声"开关（首次加载模型需几秒~几十秒）。

### 🎯 逐音色绑定 RVC 模型

设置页的"模型文件"是**全局默认模型**（所有音色共用）。想让不同音色用不同模型：

1. **音色库**页 → 点音色卡片上的 **RVC 模型** 按钮 → "绑定 / 更换 RVC 模型…" → 选择该音色专属的 `.pth`。
2. 绑定后卡片显示 `RVC · 模型：文件名`，转换/实时会优先用该音色自己的模型。
3. 解除绑定（回退全局模型）同样在该按钮菜单里。
   > 绑定只需选 `.pth`，`.index` 仍用设置页的全局配置。

### 📎 多参考音频（GPT-SoVITS 进阶）

音色卡片的 **多参考** 按钮可为一个音色挂多条参考音频，每条独立填写台词，生成时通过 v2pro API 的 `inp_refs` 参数传给模型，提升克隆稳定性与相似度。

## ❓ 常见问题 FAQ

**Q：没有 NVIDIA 显卡能用吗？**
A：可以体验全部功能流程（演示引擎）；零样本 TTS 也能用；但训练音色与实时变声需要 NVIDIA 显卡（8GB 显存即可）。

**Q：GPT-SoVITS 引擎状态一直"未连接"？**
A：确认 API 窗口是否还开着、地址是否为 `http://127.0.0.1:9880`。若本机开了代理（Clash 等），请确保没有拦截本地请求。

**Q：RVC 转换后"机器音"很重？**
A：常见原因：① 装了 CPU 版 torch（`torch.cuda.is_available()` 为 False）② 模型本身是无 f0 架构或素材带混响 ③ 男→女转换需要升调（音调 +12~+21 半音试）。

**Q：实时变声延迟/卡顿？**
A：确认 torch 是 CUDA 版；F0 算法用 `rmvpe`；关闭其他占显存的程序。

**Q：生成结果存在哪里？**
A：默认在项目 `data/output/`，可在设置里改输出目录；所有结果同时进入"历史记录"页。

**Q：mp3/m4a 导入失败？**
A：应用内置 ffmpeg（imageio-ffmpeg）负责解码，一般无需配置；如仍失败，在设置里指定 ffmpeg 路径。

**Q：能商用吗？**
A：克隆他人（含游戏角色）声音可能侵权，请仅用于个人娱乐并遵守平台规范。首次启动的授权声明请仔细阅读。

## 🔒 隐私与合规

- **100% 本地运行**：推理、训练、音频处理全部在本机完成，应用不包含任何上传逻辑，音频数据不出本机。
- **授权声明**：首次启动强制展示"授权与合规声明"，需同意后才可使用，选择记录保存在本机设置中。
