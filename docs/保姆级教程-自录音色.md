# 保姆级教程：把自己录的音，训练成专属 AI 音色

> 目标：你录音 → 电脑训练 → 用自己的音色朗读任意文字 → 发微信语音条
> 全程约 1.5 小时（大部分是电脑自己跑，你只需动手 20 分钟）
> 本教程每一步都写得极细，照着做就能成。

---

## 第 0 步：录音（最重要，决定效果）

### 录什么
- **内容**：读报纸、小说、任何连贯文字（普通话即可）。不要唱歌、不要背景音
- **长度**：**10 分钟以上**效果最好（3 分钟是底线）。可以分 30~50 段录，每段 3~10 秒一句话
- **环境**：安静房间，关空调/风扇，手机或电脑麦克风都行
- **距离**：离嘴 10~20 厘米，别喷麦

### 存哪
- 手机录的（录音文件）→ 传到电脑，放一个文件夹，例如：
  `F:\AI变声\音频\我的音色\`
- **文件名随便**（中文也可以），格式 wav/mp3 都行

> 💡 想偷懒：用手机录音 App 直接一次录 10 分钟也行，但分句录（每句一个文件）效果更好。

---

## 第 1 步：识别台词（ASR，自动的）

1. 按 `Win+R`，输入 `cmd`，回车（打开黑窗口）
2. 输入下面命令（把`我的音色`换成你的文件夹名），回车：
```
cd /d F:\AI变声\GPT-SoVITS-v2pro-20250604\GPT-SoVITS-v2pro-20250604
```
3. 再输入（整段复制粘贴，改两处：素材文件夹、输出文件夹），回车：
```
runtime\python.exe tools\asr\funasr_asr.py -i "F:\AI变声\音频\我的音色" -o "F:\AI变声\AI换声\data\asr_out\我的音色" -l zh
```
4. 等它跑完（几十秒~几分钟），会提示生成 `.list` 文件

### 检查台词（建议）
用记事本打开 `F:\AI变声\AI换声\data\asr_out\我的音色\` 里的 `.list`，长这样：
```
F:\AI变声\音频\我的音色\1.wav|我的音色|ZH|今天天气真不错，我们去公园散步吧。
```
**每行 = 一段音频 + 台词**。如果某行台词明显不对（听音频对比），改对那行的文字。

---

## 第 2 步：把台词清单复制成训练用文件

1. 复制 `.list` 文件到 `F:\AI变声\AI换声\data\asr_out\` 下，**改名为 `MYVOICE.list`**（就叫这个名，后面配置按它找）

> 注意：文件名里的路径要和音频实际位置一致（如果是你自己拷的，路径就是 `F:\AI变声\音频\我的音色\...`）

---

## 第 3 步：生成训练脚本（改 3 处就行）

模板文件我已经做好，在：
```
F:\AI变声\GPT-SoVITS-v2pro-20250604\GPT-SoVITS-v2pro-20250604\tools\
  gpt_pretrain_prep_MYVOICE_模板.py
  gpt_pretrain_train_MYVOICE_模板.py
```

### 操作
1. 复制这两个模板，改名为：
   - `gpt_pretrain_prep_myvoice.py`
   - `gpt_pretrain_train_myvoice.py`
   （`myvoice` 可换成任意**英文小写**名，如 `wozi`、`self`，两处保持一致，且不能有中文）
2. 用记事本打开 `gpt_pretrain_prep_myvoice.py`，改 **2 处**（文件里有 `TODO` 标记）：
   - 第 16 行附近：`EXP = "MYVOICE"` → `EXP = "myvoice"`（和你文件名一致）
   - 第 21 行附近：`"inp_text": r"...MYVOICE.list"` → `r"F:\AI变声\AI换声\data\asr_out\MYVOICE.list"`（改成你的 list 实际路径）
   - **`"inp_wav_dir": ""` 保持空，不要改！**
3. 用记事本打开 `gpt_pretrain_train_myvoice.py`，改 **1 处**：
   - 第 16 行：`EXP = "MYVOICE"` → `EXP = "myvoice"`
4. 保存（Ctrl+S），关闭

> 改完的驱动会生成训练产物在 `logs\myvoice\`，权重在 `SoVITS_weights_v2\myvoice_e100...` 等。

---

## 第 4 步：训练（双击菜单）

1. 复制模板 bat：`训练我的音色_模板.bat` → 改名 `训练我的音色.bat`
2. 右键用记事本打开，改顶部两行：
   ```
   set PREP=gpt_pretrain_prep_myvoice.py
   set TRAIN=gpt_pretrain_train_myvoice.py
   ```
   改成你第 3 步的文件名。保存。
3. **先关掉 API 窗口**（如果有）——否则显存不够
4. **双击** `训练我的音色.bat`，选 **4（全部执行）**
5. 挂机等待：
   - 预处理：几分钟
   - SoVITS：约 26 分钟
   - GPT：约 6 分钟
   - 窗口最后显示"全部完成"

> 训练窗口每轮会刷数字（epoch），看到 `Epoch: 100` 就是 SoVITS 好了。

---

## 第 5 步：接回使用（改一个文件 + 应用加音色）

### 5.1 做启动脚本
1. 复制桌面或整合包里的 `start-api-jixiaoman.bat` → 改名 `start-api-我的音色.bat`
2. 记事本打开，改第一行命令里的两个文件名：
   - `jixiaoman_all_e100_s3100.pth` → `myvoice_e100_s3100.pth`（训练产物，去 `SoVITS_weights_v2\` 目录看实际名字）
   - `jixiaoman_all-e30.ckpt` → `myvoice-e30.ckpt`（去 `GPT_weights_v2\` 看实际名字）
3. 保存，双击它启动 API，等 `Application startup complete`

### 5.2 应用加音色
1. 打开应用（`F:\AI变声\AI换声\AI-change-voice.exe`）
2. 左侧**音色库** → 导入你的一段录音（选你最满意的一段，5~10 秒）
3. 在音色卡上点**参考文字**，填这段录音里说的话
4. 切到**文字转语音** → 选你的音色 → 输入文字 → 生成

---

## 第 6 步：发微信语音条（可选）

1. 确认装过 VB-Cable（没有就装：https://vb-audio.com/Cable/）
2. Windows 设置 → 系统 → 声音 → 输入设备 → **CABLE Output**
3. 应用文字转语音页 → **勾选「播放到虚拟声卡」** → 点试听
4. 微信按住说话 → 语音条 = 你的音色

## 常见问题

| 问题 | 解决 |
|---|---|
| 训练窗口报 `out of memory` | API 没关；或记事本改 `max_sec` 从 20 改 15（驱动里搜 max_sec） |
| 报 `No module named 'AR'` | 必须用 bat 跑（不要自己在 cmd 里直接 python 跑驱动） |
| 报 `wrong audio path` | 素材路径不对 → 检查 MYVOICE.list 第一列的路径是不是都存在 |
| 训练完声音不像 | 录音不够/环境吵/台词没对 → 加录 10 分钟，重新跑第 1~4 步 |
| 权重文件名对不上 | 训练完去 `SoVITS_weights_v2\`、`GPT_weights_v2\` 看实际文件名，改进 start-api bat |
