# 用 AI 克隆游戏角色声音，还能发成微信语音条 —— 零基础教程

> 作者：AI 变声器项目（2026-08）
> 效果：输入任意文字 → 用游戏英雄（朵莉亚 / 姬小满 / 任意角色）的音色朗读 → 生成音频变成**微信语音条**发出去
> 本文针对**没有现成软件**的新手：只装官方免费工具，跟着点鼠标就能跑通
> 参考环境：Windows + NVIDIA RTX 4060 8GB，全程本地运行

---

## 1. 能做什么

| 能力 | 说明 |
|---|---|
| **文字转语音（TTS）** | 输入文字 → 克隆音色朗读（用朵莉亚的声音说"欢迎来到我的海洋"） |
| **克隆任意音色** | 有 3~10 分钟干净语音素材，就能训练出该音色的模型 |
| **微信语音条** | 生成音频通过虚拟声卡变成微信"按住说话"录到的声音 |

---

## 2. 需要准备

**硬件**
- Windows 电脑 + **NVIDIA 显卡**（显存 8GB 可训练；没有独显只能体验"零样本克隆"，效果打折）

**软件（全部免费开源）**
- **GPT-SoVITS 整合包**：B 站搜"GPT-SoVITS 整合包"或 GitHub（RVC-Boss/GPT-SoVITS）下载，解压即用，自带训练界面（WebUI）
- **VB-Cable**（https://vb-audio.com/Cable/）：免费虚拟声卡，微信语音条的关键
- 不需要装 Python（整合包自带运行环境）

**素材（想训练自己的音色时）**
- 目标角色语音 **10 分钟以上为佳**（3 分钟是底线）
- 来源：游戏语音包（B 站/语音包网站；同一声优**多个皮肤**音色一致可合并）、自己录音
- 尽量选**无 BGM、无音效、无混响**的纯净人声

---

## 3. 路线一：快速体验（不训练，用现成模型）

如果只是想玩玩、不想训练：

1. 下载 GPT-SoVITS 整合包，解压后双击 `go-webui.bat`，浏览器自动打开操作界面
2. **找现成模型**：B 站/模型社区搜"朵莉亚 GPT-SoVITS 模型"等，下载 .pth/.ckpt 权重文件，放到整合包对应文件夹
3. WebUI 里选好模型 + 一段参考音频 → 输入文字 → 合成试听
4. 效果满意 → 进入第 5 节"发成微信语音条"

> 零样本（不训练）也能用：WebUI 里放一段角色语音当参考，直接克隆朗读，像但不够稳。

---

## 4. 路线二：自己训练（效果最好）

### 4.1 收集素材
- 角色语音 10 分钟+（本项目实例：姬小满 3 个皮肤 122 条 / 10.2 分钟）
- 放一个文件夹，如 `D:\音频\姬小满\`

### 4.2 自动识别台词（ASR）
- 整合包自带"达摩 ASR"工具：WebUI 里有「一键预处理」，或命令行：
  ```
  runtime\python.exe tools/asr/funasr_asr.py -i "素材目录" -o "输出目录" -l zh
  ```
- 生成 `语音路径|说话人|ZH|台词` 列表 → **务必人工校对一遍**（游戏语音 ASR 常认错，如"龟不哥"实为"乖不乖"）

### 4.3 训练（两阶段，WebUI 点按钮）
| 阶段 | 内容 | 参考耗时（4060 8GB） |
|---|---|---|
| 预处理 | 文本+BERT / hubert+32k / semantic | ~3 分钟 |
| SoVITS（音色） | 100 轮，batch 4 | ~30 分钟 |
| GPT（韵律） | 30 轮，batch 2 | ~6 分钟 |

WebUI 操作：选好素材和实验名 → 依次点「1-文本预处理」「2-特征提取」「训练 SoVITS」「训练 GPT」。
（命令行版：整合包 `tools/` 下有对应脚本，改素材路径后运行）

### 4.4 合成使用
- 训练完在 WebUI「推理」页选训练好的权重 + 参考音频 → 输入文字 → 生成
- 或启动 API 服务（`api.py`，端口 9880）供程序调用

## 5. 发成微信语音条（通用关键步骤）

1. 安装 **VB-Cable**：官网下载 → 管理员运行 `VBCABLE_Setup_x64.exe` → Install
2. Windows 设置 → 系统 → 声音 → **输入设备选 CABLE Output**（微信语音条跟随系统默认输入）
3. 播放生成的音频，但**让声音走虚拟声卡不进音箱**：
   - 在合成软件里把**播放设备选成 CABLE Input**（GPT-SoVITS WebUI 或你用的播放器设置里找输出设备）
4. 电脑微信 → 聊天窗口 → **按住说话** → 放开 → 语音条 = 克隆语音 🎙️

> 要点：先播放，播放期间微信按住说话（播放时长 = 语音条时长）。
> 用完记得把 Windows 输入设备改回原麦克风，否则语音通话对方听不到你。

## 6. 经验与坑（少走弯路）

1. **数据量 > 一切**：10 分钟显著好于 3 分钟；同一声优多皮肤可合并
2. **素材越干净越像**：BGM/音效/混响拉低相似度；游戏语音带后期处理，相似度有上限，做不到 100% 一模一样
3. **台词必须与音频对得上**：ASR 错了会学错发音，务必校对
4. **偶发"机器音"**：先调低推理的 `temperature` / `top_k`、提高 `sample_steps`（64），不行再续训（SoVITS 200 轮 / GPT 50 轮）
5. **换音色 = 换模型**：训练多个角色时，一次加载一个模型
6. **训练时显存紧张**：8GB 卡训练前关掉其他占显存的程序
7. 文件编码坑：Windows 批处理脚本（.bat）要 **GBK 编码 + CRLF 换行**，否则双击闪退

## 7. 常见问题

**Q：没有 NVIDIA 显卡能玩吗？**
A：可以体验"零样本克隆"（用参考音频直接朗读，不需要训练）；训练必须有 NVIDIA 显卡。

**Q：怎么才能更像？**
A：① 加素材（10 分钟+）② 更干净素材（去 BGM/音效）③ 台词校对 ④ 多训练几轮。

**Q：微信语音条不响？**
A：①播放设备是否选了 CABLE Input ②Windows 输入设备是否为 CABLE Output ③合成服务是否在运行。

**Q：能商用吗？**
A：克隆他人（含游戏角色）声音商用可能侵权，请只用于个人娱乐并遵守平台规范。
