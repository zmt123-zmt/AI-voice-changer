> 这套是给"不想依赖 AI 助手、想自己操作"的用户。看完本手册你就能自己跑完整训练。

| 文件 | 作用 |

## 1. 训练前准备（每次必做）

1. **关掉 GPT-SoVITS API 窗口**（显存不够会 OOM 崩溃）——训练完再开
2. 确认数据在 `logs\jixiaoman_all\`（现有 122 条；加了新素材要先重新预处理）

---

## 2. 开始训练（双击 bat）

双击 `训练姬小满.bat`，选：

```
1. 预处理   → 只有改了素材/台词才需要（新素材流程见第 4 节）
2. SoVITS   → 训练音色（100 轮，约 26 分钟）
3. GPT      → 训练韵律（30 轮，约 6 分钟）
4. 全部     → 1+2+3 一次跑完（首次/大改数据用）
```

选 4 后挂机等它跑完（窗口最后显示"全部完成"）。

---

## 3. 训练完接回使用

1. 关掉训练窗口
2. 双击 `start-api-jixiaoman.bat`（桌面或本目录）起 API
3. 等 `Application startup complete`
4. 打开应用（`F:\AI变声\AI换声\AI-change-voice.exe`）→ 文字转语音 → 姬小满 → 生成

**新增权重文件**（训练产物，自动生成）：
- `SoVITS_weights_v2\jixiaoman_all_eXXX_sXXXX.pth`（最新的 eXXX 越大越新）
- `GPT_weights_v2\jixiaoman_all-eXX.ckpt`

`start-api-jixiaoman.bat` 里写的是**具体文件名**——如果训练生成的新文件名和 bat 里不一致，用记事本改 bat 里的名字。

## 4. 加新素材（进阶）

### 4.1 长音频先切片（超过 15 秒的语音）
如果新素材里有超过 15 秒的整段录音（贺文、采访、直播录像等），先用切片工具切成短句：

**拖拽即用**：把素材文件夹拖到桌面 `切分音频.bat` 上松手，自动完成：
- 长音频（>= 15s）按静音切成 4~8s 短句（转 32kHz 单声道）
- 短音频原样复制
- 输出到 `素材文件夹_train`（原文件夹旁边）

也可以手动执行：
```
cd /d F:\AI变声\AI换声
.venv\Scripts\python.exe tools\slice_audio_helper.py "素材文件夹路径" [输出文件夹] [长音频阈值秒]
```

> 为什么切：GPT 训练单条不能超过 30s，且短句（4~8s）训练更稳定。
> 工具在 `tools\slice_audio_helper.py`，算法与整合包 WebUI 切片器一致（-40dB 静音 / 最短 4s / 切点间隔 300ms / 留边 500ms），可自行改参数。

### 4.2 放素材
把新语音（wav/mp3）拷到 `F:\AI变声\音频\姬小满\新文件夹\`（长音频切片后的产物也放到这里）

### 4.3 识别台词（ASR）
打开命令提示符（Win+R → cmd），执行：
```
cd /d F:\AI变声\GPT-SoVITS-v2pro-20250604\GPT-SoVITS-v2pro-20250604
runtime\python.exe tools\asr\funasr_asr.py -i "F:\AI变声\音频\姬小满\新文件夹" -o "F:\AI变声\AI换声\data\asr_out\新素材" -l zh
```
产物是 `.list` 文件（`语音路径|说话人|ZH|台词`）。

### 4.4 合并进训练列表
用记事本打开两个文件，把新 `.list` 的内容**追加**进去（说话人统一写成 `姬小满`）：
- `F:\AI变声\AI换声\data\asr_out\姬小满_全部_final.list` ← 台词源（预处理用）

> 然后驱动脚本里的 `inp_text` 指向的 list 要包含新素材（见 4.5）

### 4.5 告诉驱动读哪个 list
用记事本打开 `tools\gpt_pretrain_prep_jixiaoman_all.py`，找到：
```
"inp_text": r"F:\AI变声\AI换声\data\asr_out\姬小满_全部_final.list",
"inp_wav_dir": "",
```
- `inp_wav_dir` **必须保持空**（多目录素材时留空才能用 list 里的完整路径）
- `inp_text` 指到合并后的 list

### 4.6 重新训练
双击 `训练姬小满.bat` 选 **4（全部）**——重新预处理 + 训练。

## 5. 调参（怎么改轮数/效果）

用记事本打开 `tools\gpt_pretrain_train_jixiaoman_all.py`，找：

| 要改的 | 找这行 | 说明 |
|---|---|---|
| SoVITS 轮数 | `base["train"]["epochs"] = 100` | 改 200 = 更久但可能更贴音色 |
| GPT 轮数 | `base["train"]["epochs"] = 30` | 改 50 = 韵律更稳（压机器音） |
| GPT 序列长度 | `base["data"]["max_sec"] = 20` | 数据多/长音频 OOM 时改小 |

> 改完保存，再跑 bat 选 2/3 即可续训（会自动从上次检查点继续）。

## 6. 常见问题

| 现象 | 原因/解决 |
|---|---|
| 训练窗口报 `out of memory` | API 没关 / max_sec 太大 → 关 API、改小 max_sec |
| 报 `AssertionError bert...` | 个别样本特征异常 → 找 AI 助手剔除坏样本（需要脚本） |
| 报 `No module named 'AR'` | 驱动没设置 PYTHONPATH → 用 bat 跑（bat 已配好） |
| 训练完声音还是不对 | 检查：台词有没有校对、素材干不干净、轮数够不够 |
| bat 双击闪退 | 文件编码坏了（必须 GBK+CRLF）→ 找 AI 助手重做 |
