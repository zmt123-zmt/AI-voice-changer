# AI 变声器需求评审与修订

> 依据：`C:\Users\ASUS\AI变声器需求文档.md`（v0.1 草案）
> 评审日期：2026-08-05

## 结论

原文档整体方向成立：本地 Windows 桌面工具、RTX 4060 8GB 显卡、音色克隆 + TTS + VC + 实时变声、中日英多语言。但其中有若干条款互相矛盾或无法按字面验收，需要在实现前修订。

## 修订项

| 编号 | 原文要点 | 问题 | 修订决定 |
| --- | --- | --- | --- |
| R1 | “一段参考音频 → 可复用的音色模型”，且 5~30 秒为最佳时长 | 5~30 秒只适用于零样本克隆（TTS）；文档同时推荐的 RVC 实时变声需要每人训练专用模型，通常 3~10 分钟干净人声 | 拆分为两条路径：零样本音色（5~30 秒，用于克隆 TTS/零样本 VC）与 RVC 训练音色（3~10 分钟，用于离线 VC 和实时变声）。音色库记录“用途”和“模型就绪状态” |
| R2 | 5.1 选型表：GPT-SoVITS 中文首选、Fish Speech 多语言首选，同时验收要求中日英 TTS 全部通过 | GPT-SoVITS 多语言较弱，单一模型无法同时满足“中文最强”和“中日英通过” | 主 TTS 引擎按语言路由：中文优先 GPT-SoVITS，日/英优先 Fish Speech 或 XTTS；应用提供引擎优先级配置 |
| R3 | 验收：相似度 MOS ≥ 4.0、可懂率 100% | 主观 MOS 与参考音频质量强相关，任何模型都无法保证固定分数；“100%”不可验收 | 改为“达到所选模型的公开基准，并在固定测试语料上做主观 A/B 对比”；应用内“相似度预估”仅作提示 |
| R4 | 用户角色含“管理员（如涉及后端）”、并发请求排队 | 本地单机桌面应用无后端、无多用户 | 删除管理员/配额；保留“生成任务排队 + 可取消”，防止同时推理抢占显存 |
| R5 | 导入支持 mp3/m4a/flac | soundfile 原生只覆盖 wav/flac/ogg，mp3/m4a 解码需要 ffmpeg | 内置 ffmpeg 解析（imageio-ffmpeg），并允许用户指定 ffmpeg 路径；安装脚本负责补齐 |
| R6 | 输出采样率 ≥ 22050Hz | AI 模型输出通常 32k/40k/48k，22.05k 偏低 | 导出格式提供 24k/44.1k/48k（默认 48k）；演示引擎使用 22.05k |
| R7 | 实时变声延迟 ≤ 150ms 为硬目标 | 可行但有前提：FP16/INT8、小分块推理、设备缓冲调优；唱歌实时变声更难 | 说话实时变声目标 ≤ 300ms、努力 ≤ 150ms；唱歌实时变声列为 P1，单独压测 |
| R8 | FV-06 人声分离（P1） | 8GB 显存下需轻量分离模型，且不宜与实时链路同时驻留 | 人声分离作为离线功能，按需加载轻量模型，不与实时链路同时占用显存 |
| R9 | “实时变声支持中日英多语言” | RVC 类模型与语言无关，输入是什么语言就保留什么语言，不需要“多语言模型” | 表述改为“实时变声语言无关，随输入语言自动适配”；无需为实时链路单独做语言识别 |
| R10 | 参数：语速 0.5~2.0x、音调 ±2 | 可做；但不同引擎实现方式不同（SAPI 用 SSML 近似，GPT-SoVITS 用 speed_factor） | 参数保持统一界面，由引擎适配层换算 |
| R11 | 合规：需提供授权声明；语音水印“待确认” | 首次使用必须展示声明 | 首次启动强制展示授权声明并记录同意；提供可选“语音水印”声明文件生成 |
| R12 | 文件大小 ≤ 100MB | 上限可保留，但应叠加时长上限防止误导入数小时音频 | 限制 ≤ 100MB 且解码时长 ≤ 10 分钟 |
| R13 | 克隆时长与效果关系 | “越短越差”过于笼统 | 明确：零样本 5~30 秒；RVC 训练 3~10 分钟；低于下限时给出警告 |
| R14 | 里程碑写死 1~2 周等周期 | 无法在开发前承诺 | 里程碑保留但不承诺周期，按迭代推进 |

## 需求确认结果

以下内容按原文档执行，不需要修改：

- Windows 10/11 桌面端（x64），仅支持 Windows
- 本地部署，音频数据不出本机
- 目标显卡 NVIDIA RTX 4060（8GB），模型按需加载、不同时驻留
- 音色库：保存、命名、列表、删除、复用
- TTS：文字 ≤ 1000 字、音色选择、语速/音调/音量、自动或手动语言、长文本分段
- VC：录音/上传、音色转换、转换强度、说话/唱歌、前后对比
- 实时变声：设备选择、音色切换、原声/变声开关、干湿比、音量调节、输入输出电平
- 结果管理：预览、导出 wav/mp3、历史记录
- 附加功能 P2：批量转换、音色混合、自定义词库（本轮实现批量转换与混合的音量调节，词库作为扩展接口）

## 本轮实现范围

1. 完整可运行的 Windows 桌面应用（PySide6），覆盖上述全部页面与流程。
2. 内置演示引擎：TTS 用 Windows 系统语音（SAPI），VC/实时用本地 DSP 变调变声，保证无模型也能端到端跑通。
3. 真实 AI 引擎适配层：GPT-SoVITS（TTS/零样本克隆）与 RVC（VC/实时），安装模型后即可切换，无需改代码。
4. 首次启动合规声明、任务队列、音质校验、历史记录、导出。

不在本轮承诺范围：模型权重的下载与训练（需要网络和参考音频），以及由此带来的主观 MOS 达标。
